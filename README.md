# Сайт-портфолио

Статический сайт: 11ty для шаблонов, дальше — чистый HTML, CSS по БЭМ и один JS-файл.
Без сборщиков, без минификации: исходник читается в DevTools и это осознанно.

## Команды

```bash
npm ci          # установить зависимости
npm run build   # собрать в _site
npm run serve   # локальный сервер с пересборкой
```

## Структура

```
src/
├─ _data/            данные: сайт, навигация, кейсы
├─ _includes/        макеты и партиалы Nunjucks
├─ assets/css/       styles.css — единственный файл стилей
├─ assets/js/        main.js — единственный файл скриптов
├─ assets/fonts/     Literata + Inter, subset woff2
├─ index.njk         главная
└─ 404.njk
```

## Деплой

Push в `main` → GitHub Actions собирает и публикует на GitHub Pages.

## Известные пробелы

- Поле `retro` в данных кейсов содержит `TODO`: блок «что бы сделал иначе» не выводится,
  пока владелец не пришлёт текст.
- Скриншоты кейсов сняты владельцем, обрезаны и сжаты в WebP (1440×810 и 540×1170).
- Aнглийские тексты кейсов написаны отдельно и требуют вычитки носителем.

## Проверки

- Lighthouse на живом домене: 100/100/100/100, LCP 1,2 с, CLS 0.
- axe-core (WCAG 2.1/2.2 AA + best-practice): 0 нарушений на главной, кейсе и резюме.
- Внутренние ссылки: 0 битых (проверка скриптом по собранному `_site`).
- Печать `/cv/`: 2 страницы A4, ничего не обрезано.
