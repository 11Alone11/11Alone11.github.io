# Сайт-портфолио

Одна страница: работа, опыт, контакты. Резюме — PDF, собирается из печатной версии этой же
страницы. 11ty только склеивает HTML; стили и скрипты — один файл, без сборщиков и минификации.

## Живой сайт

https://11alone11.github.io

## Команды

```bash
npm ci          # установить зависимости
npm run build   # собрать в _site
npm run serve   # локальный сервер с пересборкой
```

## Структура

```
src/
├─ _data/
│  ├─ site.yaml          имя, контакты, репозиторий
│  ├─ experience.yaml    пять позиций для блока «Опыт» и печати
│  ├─ works.yaml         порядок кейсов
│  └─ cases/*.yaml       три кейса: контекст, решения, метрики, артефакты
├─ _includes/
│  ├─ layouts/base.njk
│  └─ partials/          шапка, подвал, кейс, лайтбокс, JSON-LD
├─ assets/
│  ├─ css/styles.css     один файл, @layer
│  ├─ js/main.js         карусель, лайтбокс, слайдер, тема, печать
│  ├─ fonts/             Literata + Inter, woff2
│  ├─ img/cases/         WebP 720 / 1080 / 1440
│  └─ resume.pdf         готовый PDF для скачивания
├─ index.njk             вся страница
└─ 404.njk
```

## Что на странице

- Герой с каруселью трёх кейсов и двумя действиями: «Смотреть работы» и «Скачать PDF».
- Три кейса целиком: контекст, ограничения, три решения с ценой, результат, слайдер «до/после»,
  галерея с лайтбоксом, ссылка на живой продукт.
- Опыт, стек, образование и языки — они же уходят в PDF.
- Контакты, тема, печать.
- Удалены: отдельные страницы `/work/`, `/cv/`, `/stack/`, английская версия, командная палитра,
  «анатомия страницы», живой вес в подвале и декоративная нумерация страниц.

## PDF

`src/assets/resume.pdf` — одна страница A4, собранная из печатных стилей `@media print`.
Если меняются опыт или контакты, PDF пересобирается печатью страницы: кнопка «Печать» →
«Сохранить как PDF» → заменить `src/assets/resume.pdf`.

## Проверки

- Lighthouse mobile: локально с gzip — 99 / 100 / 100 / 100; на живом домене — **100 / 100 / 100 / 100**, LCP 1,4 с, CLS 0.
- axe-core, светлая и тёмная темы: 0 нарушений.
- 320 / 360 / 390 / 768 / 1024 / 1440: без горизонтального скролла.
- Печать: 1 страница A4.
- Без JS: контент, ссылки, тема по системе, изображения открываются в новой вкладке.

## Известные пробелы

- Блок «что бы я сделал иначе» скрыт: в кейсах нет текста `retro`.
- У veloman и БИРЖЕВИКа нет публичных метрик — это сказано прямо, вместо выдуманных цифр.
- Скриншоты БИРЖЕВИКа — композит из двух мобильных экранов; исходные кадры не подставляются
  отдельно.
